# 按需使用

## 看原文与改计划

- `--list --pages 1-3`：每项一行摘要；加 `--pending` 仅列未填写项，包含有意保留的公式/数字。
- `--show 3 2`：第3页第2块全文及紧凑 span 清单；`s` 从0计数。
- `--merge 3 2-4`：把明确选择的同页块合成 RECT，取坐标并集，替换原条目，保留已填译文供重新校对。不自动跨栏或猜测应合并哪些块。
- `--cells 3 2`：按视觉行和明显列间距拆分一个未填写表格块，生成 RECT 候选。检查合并单元格、多行单元格与列边界；数字和模型名可留空。这是辅助拆分，不是完整表格理解。
- 上述修改会保留一份 `plan.jsonl.bak`；只改当前单文件，不生成状态镜像。
- `--preview 3-5,7`：将所传 PDF 的页面渲染到 `<PDF>.preview/`；要查看译本，就把译本作为输入。

## 条目

- PARA：`{"p":1,"b":2,"type":"PARA","dst":"译文"}`。
- SPAN：`{"p":3,"b":2,"s":0,"type":"SPAN","dst":"方法"}`，沿原基线写单行。由 PARA 改为 SPAN 时，可以保留原块 src；脚本会校验它确实属于该块。
- RECT：`{"p":3,"type":"RECT","rect":[50,100,120,110],"dst":"方法"}`，默认取附近原文字号，可用 `size` 指定。不要盖到邻近数字/公式。
- `style`：body / heading / headc / title / caption；caption 为居中正文。也可显式设 `align` 为 left/center/right。
- 行距默认1.1，不强行撑满原矩形。确需调整时设 `lineheight`（1到2）。
- 空 dst 保留原文，无需维护 status。缩字号超过10%记录在报告 warnings 中，未写入的条目记录在 issues 中。

`--plan-file path.jsonl` 为重建/查看/验证选择其他单文件计划。旧任务先合并实际生效的译文；脚本不自动加载 translations/ 或执行 translations.py。

独立公式保留原对象。PARA 内的行内公式没有自动数学排版；保留其精确符号与语义，必要时拆区域，勿随意扩大覆盖范围。旋转标注与译文区域相交时会报告并跳过该条，不自动抹除。
